Nothing about galamsey should go missing.

Ghanaian news sites reorganise, paywall and go dark, and reporting on illegal mining disappears with them. This crawler reads the newsrooms every six hours, keeps what is about galamsey, and holds it — headline, date, place, figures, source and a snapshot — in one archive you can search.

How it works

Read, filter, classify, keep

A scheduled job, not a live service. News sites do not let a browser fetch their feeds directly, so the crawler runs on a timer and commits what it finds.

READ

Feeds, every six hours

RSS from Ghanaian newsrooms plus targeted news queries for galamsey, NAIMOS operations, forest reserves and river turbidity.

FILTER

Keep what is on topic

An item survives only if it mentions illegal mining, excavators, changfan, forest reserves or a named task force.

CLASSIFY

Sort and count

Each item is typed by subject, and any figures for arrests, excavators, hectares or NTU are pulled out of the text.

PLACE

Match to a location

Text is matched against a gazetteer of 140 Ghanaian mining towns, reserves and rivers. Nothing is guessed at.

KEEP

Snapshot and hold

New links are pushed to the Internet Archive in the background, so a copy survives even when the original page is taken down.

FOLLOW

Link reports into stories

Records sharing distinctive names — a company, a concession, a defendant — are threaded together, so a case can be read from the raid through to the verdict.

REACH BACK

Backfill the years before

A separate pass mines the GDELT news index and the Internet Archive's URL index for coverage published long before this crawler existed.

How far back it reaches

Live feeds
Days to weeks
RSS carries only the last few dozen items. The forward crawl builds the archive from the day it starts running.
GDELT index
2017 onward
Real headlines, real publish dates, structured and reliable — but the index simply does not exist before January 2017.
Wayback URL index
Roughly 2010 onward
Reaches as far back as the Archive crawled each outlet, but only recovers a headline where the outlet put it in the web address. Ghanaian sites moved to readable addresses between 2010 and 2014; before that most articles were numbered, and the text is unrecoverable this way.
# run it once
node crawler/crawl.js

# run it and snapshot every new link to the Internet Archive
ARCHIVE=1 node crawler/crawl.js

# reach backwards through years already published
node crawler/backfill.js gdelt   2017 2026
node crawler/backfill.js wayback 2010 2016

# or let GitHub Actions run the forward crawl every six hours
.github/workflows/crawl.yml → writes data/incidents.json

Records marked verified were read from the published source and checked by hand; the crawler never overwrites them. Everything else carries the outlet's own headline and is a lead, not a finding. Figures are reproduced as their sources state them. Named individuals and companies appear only as their sources named them, and allegations are recorded as allegations.

Before you send anything
Do not confront anyone and do not photograph people. Note the place, not the faces. Illegal mining sites are guarded, and reporters have been threatened.
NAIMOS
The National Anti-Illegal Mining Operations Secretariat runs the joint task forces behind most of the arrests in this archive.
Forestry Commission
For anything inside a gazetted forest reserve.
Ghana Police Service
Emergency 191 or 112. Ask for the District Commander if equipment is on site now.
EPA Ghana
For water discolouration, chemical smells, fish kills, or an abandoned pit left unfilled.
